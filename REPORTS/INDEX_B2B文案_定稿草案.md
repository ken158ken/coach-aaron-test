### 3-1. 分組架構（客戶定案的三組）

```
第一組｜變現陪跑方案（主方案）    courses #1–3   NT$ 32,800 / 59,800 / 118,000
第二組｜線上課程（單點突破）       courses #4–7   NT$ 480 / 980 / 1,980 / 1,980
第三組｜一對一諮詢（客製）        courses #8–9   NT$ 18,000 / 30 天
```

> **分組理由**：這三組正好對應教練的三種購買情境——「我要整套解法」「我只缺某一塊」「我需要有人針對我的狀況給答案」。價格帶也呈天然階梯（幾百元 → 一萬八 → 三萬到十一萬），讓訪客自己對號入座，不必比較。
> **呈現順序建議**：先「線上課程」（低門檻入口）→「一對一諮詢」→「變現陪跑方案」（高價主力壓軸）為漏斗式；若要主打旗艦，則反過來把陪跑放第一。**建議採後者**（陪跑 → 線上課 → 一對一），因為陪跑是主力商品，且首屏空間最貴。
