# 顯示名稱 500 錯誤 + 舊名稱未載入 修復報告

> **時間戳記**: 2026-02-15T23:00:00+08:00 (ISO 8601)  
> **延續**: `AVATAR_DISPLAY_NAME_FIX_2026-02-15T22-00-00+08-00.md`

---

## 📋 問題描述

### 1. 更新顯示名稱回傳 500 錯誤

- **症狀**: PUT `/api/user/profile` 回傳 HTTP 500
- **瀏覽器 Console 錯誤**:
  ```
  code: "42703"
  detail: "column users.gender does not exist"
  ```
- **根因**: `users` 資料表中**不存在 `gender` 欄位**（實際欄位為 `sex`），但 `backend/routes/user.ts` 的 GET/PUT profile 路由都在 `.select()` 中查詢 `gender`，導致 PostgreSQL 回傳 `42703 undefined_column` 錯誤

### 2. 頁面載入時舊名稱未顯示

- **症狀**: 進入會員中心，「顯示名稱」輸入框為空，沒有顯示使用者的舊名稱
- **根因**: 後端 `/api/auth/me` 回傳的 user 物件使用 **camelCase**（`displayName`、`userId`、`avatarUrl`），但前端 `User` 型別定義使用 **snake_case**（`display_name`、`user_id`、`avatar_url`）。MemberCenter 用 `user.display_name` 取值 → `undefined` → 回退 `user.name` → 也 `undefined` → 空字串

---

## 🔧 修復方案

### 修改檔案清單

| 檔案                                   | 修改類型 | 說明                                                 |
| -------------------------------------- | -------- | ---------------------------------------------------- |
| `backend/routes/user.ts`               | 修改     | 移除所有 `gender` 欄位引用（SELECT、驗證邏輯、常數） |
| `frontend/src/context/AuthContext.tsx` | 修改     | 新增 `normalizeUser` 函式，camelCase→snake_case 映射 |

### `backend/routes/user.ts` 詳細變更

1. **GET /profile**: SELECT 移除 `gender`

   ```diff
   - "user_id, username, email, display_name, phone_number, avatar_url, avatar_base64, gender, created_at"
   + "user_id, username, email, display_name, phone_number, avatar_url, avatar_base64, created_at"
   ```

2. **PUT /profile**: SELECT 移除 `gender`

   ```diff
   - "user_id, username, email, display_name, phone_number, avatar_url, gender"
   + "user_id, username, email, display_name, phone_number, avatar_url"
   ```

3. **移除 `VALID_GENDERS` 常數**（users 表無 gender 欄位）
4. **移除性別驗證區塊**（`if (gender !== undefined) { ... }`）
5. **req.body 解構移除 `gender`**
6. **allowedFields 移除 `"gender"`**

### `frontend/src/context/AuthContext.tsx` 詳細變更

新增 `normalizeUser()` 函式，處理 camelCase↔snake_case 映射：

```typescript
const normalizeUser = (raw: Record<string, unknown>): User => ({
  user_id: raw.user_id ?? raw.userId,
  display_name: raw.display_name ?? raw.displayName ?? raw.name ?? raw.username,
  avatar_url: raw.avatar_url ?? raw.avatarUrl,
  phone_number: raw.phone_number ?? raw.phoneNumber,
  // ...
});
```

在 `checkAuth`、`login`、`register` 三處 `setUser()` 呼叫中加入 `normalizeUser` 正規化。
