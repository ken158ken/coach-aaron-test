> **報告時間**: 2026-02-14T14:00:00+08:00 (ISO 8601)

> **影響範圍**: 9 個檔案，312 行新增，163 行刪除

## 📋 問題描述

1. **Navbar 手機版管理員按鈕不顯示** — 使用 `user.isAdmin`（User 物件可選屬性）而非 AuthContext 的 `isAdmin` 狀態
2. **AdminLayout 側邊欄在手機預設展開** — `sidebarOpen` 初始值 `true`，手機載入即覆蓋內容
3. **AdminSidebar 缺乏手機行為** — 無 overlay 模式、無自動關閉、無關閉按鈕
4. **DataTable 手機卡片溢出** — 主要欄位文字無限延伸、次要欄位限制 4 個、無手機排序
5. **觸控裝置操作按鈕不可見** — `opacity-0 group-hover:opacity-100` 在觸控裝置永不觸發
6. **管理頁面 Header 文字/間距不響應** — 標題 `text-2xl` 在小螢幕過大

---

## ✅ 修復項目

### 1. Navbar.tsx — 管理員按鈕修復

| 問題                                             | 修復                               |
| ------------------------------------------------ | ---------------------------------- |
| `user.isAdmin` 不可靠                            | 改用 `useAuth()` 的 `isAdmin` 狀態 |
| 桌面版 (`xl:flex`) 與手機版 (`xl:hidden`) 不一致 | 統一使用 context `isAdmin`         |

### 2. AdminLayout.tsx — 完全重寫

| 功能            | 實作                                                    |
| --------------- | ------------------------------------------------------- |
| SSR-safe 初始值 | `sidebarOpen: false`, `isMobile: false`                 |
| 螢幕偵測        | `MOBILE_BREAKPOINT = 1024px` + `handleResize()`         |
| 桌面預設展開    | `useEffect` mount 時偵測寬度，≥1024 自動展開            |
| 手機遮罩        | `bg-black/60 backdrop-blur-sm z-30`，點擊關閉           |
| 主內容偏移      | `!isMobile && sidebarOpen ? lg:ml-64 : lg:ml-20`        |
| 響應式 header   | 漢堡選單、前台連結（手機圖示/桌面文字）、compact 控制項 |

### 3. AdminSidebar.tsx — 手機/桌面雙模式

| 模式             | 行為                                                   |
| ---------------- | ------------------------------------------------------ |
| 手機 (isMobile)  | `translate-x-0` / `-translate-x-full` + `z-40` overlay |
| 桌面 (!isMobile) | `w-64` 展開 / `w-20` 收合 + `z-20` 固定                |
| 手機關閉按鈕     | 右上角 X 按鈕，`onClick={onToggle}`                    |
| 導航自動關閉     | 所有 `<Link>` 加入 `onClick={onNavigate}`              |
| 底部返回連結     | 同樣加入 `onClick={onNavigate}`                        |

### 4. DataTable.tsx — 手機卡片改進

| 問題           | 修復                              |
| -------------- | --------------------------------- |
| 主要欄位溢出   | `min-w-0 break-words`             |
| 次要欄位限制 4 | 移除 `.slice(0, 4)`，顯示全部     |
| 無手機排序     | 新增 `<select>` 排序下拉選擇器    |
| 卡片間距過大   | `p-3 sm:p-4`，`gap-x-3 gap-y-1.5` |

### 5. 觸控裝置修復 (3 檔案)

| 檔案                   | 修復                                      |
| ---------------------- | ----------------------------------------- |
| AdminArticles.tsx L608 | `md:opacity-0 md:group-hover:opacity-100` |
| AdminCourses.tsx L570  | `md:opacity-0 md:group-hover:opacity-100` |
| AdminVideos.tsx L415   | `md:opacity-0 md:group-hover:opacity-100` |

**效果**: 手機/平板始終顯示操作按鈕，桌面保持 hover 動畫效果

### 6. 管理頁面 Header RWD (5 頁面)

| 元素          | 修改前         | 修改後                 |
| ------------- | -------------- | ---------------------- |
| 標題 h1       | `text-2xl`     | `text-xl sm:text-2xl`  |
| 描述 p        | 無響應式       | `text-sm sm:text-base` |
| 外層間距      | `mb-8`         | `mb-6 sm:mb-8`         |
| gap           | `gap-4`        | `gap-3 sm:gap-4`       |
| 篩選器        | 缺 `flex-wrap` | 加入 `flex-wrap`       |
