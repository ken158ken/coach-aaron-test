## ✅ 完成項目

### 1. localStorage 草稿自動暫存

| 功能         | 說明                                   |
| ------------ | -------------------------------------- |
| **自動儲存** | 每 30 秒自動儲存到 `localStorage`      |
| **恢復草稿** | 進入頁面時檢測是否有草稿，詢問是否恢復 |
| **手動儲存** | 點擊「儲存草稿」按鈕立即儲存           |
| **發布清除** | 發布成功後自動清除草稿                 |
| **離開提醒** | 有未儲存變更時會提醒使用者             |

#### Storage Keys

- **文章草稿**: `article_draft`
- **文章分類**: `article_categories`
- **課程草稿**: `course_draft`
- **課程分類**: `course_categories`

#### 儲存格式

```json
{
  "article": {
    "title": "...",
    "slug": "...",
    "excerpt": "...",
    "category": "...",
    "tags": [],
    "coverImage": "...",
    "content": "...",
    "status": "draft"
  },
  "savedAt": "2025-01-21T08:00:00.000Z"
}
```

### 2. 分類管理功能

| 功能              | 說明                              |
| ----------------- | --------------------------------- |
| **查看分類**      | 在分類下拉選單旁點擊「管理分類」  |
| **新增分類**      | 輸入名稱後按 Enter 或點擊「新增」 |
| **刪除分類**      | 在分類列表點擊「刪除」按鈕        |
| **自動生成 slug** | 根據名稱自動生成網址友善的 slug   |

### 3. 使用說明 Modal

在頁面頂部加入問號 (?) 圖示按鈕，點擊後顯示完整使用說明。

#### 說明內容包含：

##### 🖊️ 基本操作

1. 輸入標題
2. 撰寫內容
3. 儲存草稿
4. 發布文章/課程

##### 🔧 工具列按鈕說明

| 按鈕             | 功能     | 說明                 |
| ---------------- | -------- | -------------------- |
| B I U            | 文字格式 | 粗體、斜體、底線     |
| H1 H2 H3         | 標題大小 | H1 最大，H3 最小     |
| • 列表 / 1. 列表 | 列表     | 項目符號或編號列表   |
| ⬅ ⬛ ➡           | 對齊     | 文字對齊：左、中、右 |
| 🖼️ 圖片          | 插入圖片 | 貼上圖片網址         |
| 🎬 影片          | 插入影片 | 貼上 YouTube 網址    |

##### 📋 右側設定說明

- 網址代稱
- 摘要/簡介
- 分類（含管理功能）
- 標籤
- 封面圖片
- 價格/時長/難度（課程專屬）

##### 💡 小技巧

- 草稿每 30 秒自動儲存
- 滑鼠停在按鈕上會顯示說明
- 建議使用 Cloudinary 上傳圖片
