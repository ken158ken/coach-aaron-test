## 4. SSR 全域修復 (Vercel)

### 根因分析

**症狀**: Vercel 部署後檢視原始碼顯示 `<!--ssr-outlet-->` 和 `<!--ssr-head-->` 未被替換

**根因**: `api/ssr.js` 中的檔案路徑解析錯誤

```
舊路徑: path.resolve(process.cwd(), "index.html")
       → /var/task/index.html (不存在！)

Vercel 部署架構:
- outputDirectory: "frontend/dist/client" → CDN 靜態分發
- 但 CDN 內容不會放到 serverless 函數的 process.cwd()
- includeFiles 只包含了 entry-server.js，沒有 index.html
```

### 修復方案

#### 4.1 `vercel.json` — includeFiles 擴展

```json
// 舊
"includeFiles": "frontend/dist/server/entry-server.js"

// 新
"includeFiles": "{frontend/dist/server/**,frontend/dist/client/index.html}"
```

- 將 index.html 也加入 serverless 函數可存取範圍
- server bundle 改用 `**` glob 確保所有 chunk 都被包含

#### 4.2 `api/ssr.js` — 完全重寫

| 改進            | 說明                                                             |
| --------------- | ---------------------------------------------------------------- |
| 多路徑候選搜尋  | `findFile()` 工具函數，依序嘗試多個候選路徑                      |
| 增強偵錯日誌    | `listDir()` 遞迴列出目錄結構，快速定位檔案問題                   |
| 雙模式注入      | 支援 `<!--ssr-outlet-->` 和 `<div id="root"></div>` 兩種注入方式 |
| CSR fallback 鏈 | SSR 失敗時回傳純靜態 HTML                                        |
| 移除開發腳本    | 自動清除 `/src/entry-client.tsx` 引用                            |
| UTF-8 編碼      | Content-Type 加入 `charset=utf-8`                                |
| Cache-Control   | `s-maxage=10, stale-while-revalidate=60` 取代 no-cache           |

#### 4.3 `vite.config.ts` — SSR 構建偵測修正

```typescript
// 舊 (永遠不會觸發)
const isSSRBuild = mode === "ssr";

// 新 (Vite 5 正式 API)
export default defineConfig(({ command, mode, isSsrBuild }) => { ... });
```

#### 4.4 `entry-server.tsx` — 錯誤處理

- `render()` 函數加入 try-catch 包裝
- SSR 渲染失敗時回傳 `{ html: "", head: "" }` 讓客戶端接管

### SSR 架構圖

```
Vercel 部署架構:

  ┌─────────────────────────────────────────────────┐
  │  CDN (outputDirectory: frontend/dist/client)    │
  │  ├── assets/*.js (hashed bundles)               │
  │  ├── assets/*.css                               │
  │  └── favicon.svg                                │
  └─────────────────────────────────────────────────┘
                    ↑ 靜態資源請求

  ┌─────────────────────────────────────────────────┐
  │  vercel.json rewrites                           │
  │  /api/(*)  → api/server.js (後端 API)           │
  │  /(*)      → api/ssr.js   (SSR 渲染)            │
  └─────────────────────────────────────────────────┘
                    ↓ HTML 請求

  ┌─────────────────────────────────────────────────┐
  │  api/ssr.js (Serverless Function)               │
  │  ├── 讀取 frontend/dist/client/index.html       │
  │  ├── import frontend/dist/server/entry-server.js│
  │  ├── render(url) → { html, head }               │
  │  ├── 替換 <!--ssr-outlet--> 和 <!--ssr-head-->  │
  │  └── 回傳完整 HTML (含 SSR 內容 + head 標籤)    │
  └─────────────────────────────────────────────────┘
```
