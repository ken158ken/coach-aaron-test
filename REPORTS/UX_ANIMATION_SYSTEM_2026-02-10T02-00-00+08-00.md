# 全域 UX 動畫系統升級報告

> **時間戳記**: 2026-02-10T02:00:00+08:00  
> **版本**: Phase 4 — Global Animation Overhaul

---

## 📋 問題描述

用戶反映專案整體互動體驗單調：

- 大量 DOM 元素 hover 無任何動畫回饋
- 頁面切換無轉場效果（直接跳轉）
- 手機選單即時出現/消失，無過渡
- 表單聚焦行為在不同元件間不一致
- Modal 彈出無進場動畫

需求：「需要有專業度、低調但是又現代感的動畫，避免加入不適當的動畫」

---

| 手機選單      | 無動畫，瞬間出現                    | 🔴 嚴重  |

## ✅ 解決方案

### 1. 全域動畫 CSS 基礎設施

**tailwind.config.ts** — 擴展動畫 utility：

- `fade-in` / `fade-in-up` / `fade-in-down`
- `slide-in-right` / `slide-in-left`
- `scale-in` / `stagger-fade-in`

**index.css** — ~150 行新增動畫 CSS：

- 頁面轉場 keyframes（`pageEnter` / `pageExit`）
- 滾動入場系統（`.scroll-reveal` + `.is-visible`）
- Stagger 延遲（`.stagger-1` ~ `.stagger-9`）
- 手機選單（`mobileMenuSlideIn` + `mobileMenuItemFadeIn`）
- 按鈕按壓（`.btn-press`）
- 連結底線（`.link-underline`）
- Modal 進場（`modalOverlayIn` + `modalContentIn`）
- 表單聚焦線（`.input-focus-line`）

### 2. React 專用 Hook 與元件

| 檔案                 | 功能                                                                      |
| -------------------- | ------------------------------------------------------------------------- |
| `useScrollReveal.ts` | IntersectionObserver hook，自動觀察 `.scroll-reveal` 子元素，觸發入場動畫 |
| `getStaggerClass()`  | 工具函式，根據 index 產生 `stagger-N` class                               |
| `PageTransition.tsx` | 路由切換動畫包裝器，exit 200ms → enter 400ms                              |

### 3. 元件級改動

- **Layout.tsx**: Outlet 包裝 PageTransition
- **Navbar.tsx**: 手機選單 clip-path 展開 + 選項 stagger 進場
- **Footer.tsx**: `link-underline` + 社群圖示光暈
- **Courses.tsx / Articles.tsx**: 卡片 scroll-reveal stagger 入場
- **Dialog.tsx**: `modal-overlay-enter` + `modal-content-enter`
- **GlowButton / PillButton**: `focus-visible:ring-2` 鍵盤焦點環
- **Select / Textarea / SearchInput**: 統一 `focus:ring-2` 聚焦環

### 4. 無障礙設計

- `@media (prefers-reduced-motion: reduce)` 全域停用動畫
- `useScrollReveal` 偵測偏好後直接標記可見
- `PageTransition` 尊重減少動畫設定

## 📐 設計原則

1. **低調專業**：所有動畫時長控制在 200ms ~ 600ms，避免浮誇
2. **效能優先**：純 CSS 動畫（無額外 JS 動畫庫），利用 GPU 加速的 `transform` / `opacity`
3. **一致性**：相同類型互動使用相同動畫參數（easing、duration）
4. **無障礙**：完整的 `prefers-reduced-motion` 支援
5. **漸進增強**：動畫為純增強體驗，移除後功能不受影響
