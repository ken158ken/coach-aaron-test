## ✅ 修正內容

### 1. Vite 配置優化

**檔案**: `frontend/vite.config.ts`

#### 修正前

```typescript
export default defineConfig({
  build: {
    outDir: "dist/client", // 只有客戶端構建
    // ...
  },
});
```

#### 修正後

```typescript
export default defineConfig(({ command, mode }) => {
  const isSSRBuild = mode === "ssr";

  return {
    build: isSSRBuild
      ? {
          // SSR 構建配置
          outDir: "dist/server",
          ssr: true,
          rollupOptions: {
            input: "src/entry-server.tsx",
            output: {
              format: "esm",
              entryFileNames: "[name].js",
            },
          },
        }
      : {
          // 客戶端構建配置
          outDir: "dist/client",
          // ...
        },
    ssr: {
      // 確保這些套件不被外部化
      noExternal: [
        "react-icons",
        "gsap",
        "react-helmet-async",
        "three",
        "@react-three/fiber",
        "@react-three/drei",
      ],
    },
  };
});
```

**改進點**：

- 使用 mode 判斷構建類型
- 分離 SSR 和客戶端構建配置
- 明確指定 SSR 輸出格式為 ESM
- 擴展 noExternal 列表，包含 Three.js 相關套件

const possibleTemplatePaths = [

const serverDir = path.resolve(__dirname, "../frontend/dist/server");

const serverModulePath = path.resolve(serverDir, "entry-server.js");

**改進點**：

- 移除複雜的路徑嘗試邏輯
- 直接使用 Vercel includeFiles 指定的路徑

- 增加目錄內容偵錯日誌

## 🔧 SSR 執行流程

### 1. 請求進入

```
用戶請求 → Vercel → /api/ssr
```

### 2. 載入模組

```javascript
// 動態載入 ESM
const serverModule = await import(`file://${serverModulePath}`);
const { render } = serverModule;
```

### 3. 渲染 HTML

```javascript
const { html, head } = render(url);
```

### 4. 注入內容

```javascript
let finalHtml = template.replace("<!--ssr-outlet-->", html);
finalHtml = finalHtml.replace("<!--ssr-head-->", head);
```

### 5. 回傳響應

```javascript
res
  .setHeader("Content-Type", "text/html")
  .setHeader("Cache-Control", "no-cache")
  .end(finalHtml);
```

#### 2. 查看 Network 面板

- **SSR 成功**：初始 HTML 文件大小應該 > 50KB
- **SSR 失敗**：HTML 很小，只有模板

#### 3. curl 測試

```bash
curl https://你的網址.vercel.app/ | grep "flex flex-col min-h-screen"
# 有輸出 = SSR 成功
```

#### 4. Google 搜尋測試

```
site:你的網址.vercel.app
```

- **SSR 成功**：能看到頁面標題、描述
- **SSR 失敗**：標題是預設的

## 📋 技術細節

### entry-server.tsx

```typescript
export function render(url: string): RenderResult {
  const helmetContext: any = {};

  const html = renderToString(
    <React.StrictMode>
      <HelmetProvider context={helmetContext}>
        <StaticRouter location={url}>
          <App />
        </StaticRouter>
      </HelmetProvider>
    </React.StrictMode>,
  );

  const { helmet } = helmetContext;
  const head = helmet
    ? [
        helmet.title?.toString() || "",
        helmet.meta?.toString() || "",
        helmet.link?.toString() || "",
        helmet.script?.toString() || "",
      ].join("\n")
    : "";

  return { html, head };
}
```

**關鍵點**：

- 使用 `StaticRouter` 而非 `BrowserRouter`
- `HelmetProvider` 收集所有 SEO meta tags
- `renderToString` 將 React 組件轉為 HTML 字串

## ⚠️ 注意事項

### 1. 客戶端 Hydration

SSR 後，客戶端會進行 hydration（注水）：

```javascript
// entry-client.tsx
hydrateRoot(document.getElementById("root")!, <App />);
```

**重要**：伺服器和客戶端渲染的 HTML 必須一致！

### 2. 避免使用僅瀏覽器 API

```typescript
// ❌ 錯誤 - SSR 會報錯
const width = window.innerWidth;

// ✅ 正確
const width = typeof window !== "undefined" ? window.innerWidth : 0;
```

### 3. Three.js 特別處理

Three.js 需要在客戶端渲染：

```typescript
const [mounted, setMounted] = useState(false);

useEffect(() => {
  setMounted(true);
}, []);

return mounted ? <ThreeScene /> : null;
```
