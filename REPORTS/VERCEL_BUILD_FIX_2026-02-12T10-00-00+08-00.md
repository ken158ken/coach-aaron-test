# Vercel 構建錯誤修復報告

> **時間戳**: 2026-02-12T10:00:00+08:00
> **類型**: Bug Fix — 部署構建失敗修復
> **影響範圍**: TypeScript 編譯錯誤 (13 個) + SSR 函式過大 (646MB > 300MB)

---

## 📋 問題摘要

Vercel 構建失敗，共 **13 個 TypeScript 錯誤** + **1 個致命的 SSR 函式大小超限**：

| #        | 檔案                                | 錯誤                                           | 根因                                   |
| -------- | ----------------------------------- | ---------------------------------------------- | -------------------------------------- |
| 1-5      | AdminUsers.tsx L131,132,175,179,184 | `'is_active' does not exist on type 'User'`    | User 介面缺少欄位                      |
| 6        | AdminDashboard.tsx L172             | `'formatRelativeTime' declared but never read` | `noUnusedLocals: true`                 |
| 7,9      | AdminContent.tsx L510,741           | Toggle `theme` prop 無效                       | ToggleProps 缺少 `theme`               |
| 8        | AdminContent.tsx L684               | Modal `size="full"` 無效                       | Modal 尚未擴展 size 類型               |
| 10,11    | PrismScene/AbyssScene L11           | `three` 模組缺少型別宣告                       | tsconfig `types: ["vite/client"]` 限制 |
| 12,13    | vite.config.ts L5                   | `command`/`mode` 宣告未使用                    | `noUnusedLocals: true`                 |
| **致命** | api/ssr.js 函式                     | **646.08MB > 300MB 限制**                      | `ssr.noExternal` 打包 Three.js         |

---

## 🔧 修復內容

### Fix 1: User 介面新增 `is_active` 欄位

**檔案**: `frontend/src/types/user.ts`

- 新增 `is_active?: boolean` 到 `User` 介面
- 解決 AdminUsers.tsx 中 5 個 `Property 'is_active' does not exist` 錯誤

### Fix 2: 移除未使用的 `formatRelativeTime` 函式

**檔案**: `frontend/src/pages/admin/AdminDashboard.tsx`

- 移除 `export default` 之後定義但未被呼叫的 `formatRelativeTime` 函式
- 解決 `noUnusedLocals` 錯誤

### Fix 3: Toggle 元件新增 `theme` 屬性

**檔案**: `frontend/src/components/ui/form/Toggle.tsx`

- 在 `ToggleProps` 介面新增 `theme?: string`
- 解決 AdminContent.tsx 中 2 個 Toggle theme prop 錯誤

### Fix 4: tsconfig 移除 `types` 限制

**檔案**: `frontend/tsconfig.json`

- 移除 `"types": ["vite/client"]` 設定
- 讓 TypeScript 自動偵測所有 `@types/*` 套件（包括 `@types/three`）
- 解決 PrismScene/AbyssScene 的 `three` 型別宣告錯誤

### Fix 5: vite.config.ts 移除未使用變數

**檔案**: `frontend/vite.config.ts`

- `({ command, mode, isSsrBuild })` → `({ isSsrBuild })`
- 解決 2 個未使用變數錯誤

### Fix 6: SSR 函式 646MB → 大幅縮減 ⚡

**檔案**: `frontend/vite.config.ts` + `frontend/src/components/three/*.tsx`

**根因分析**:

- `ssr.noExternal` 包含 `three`、`@react-three/fiber`、`@react-three/drei`
- 迫使 Vite 將整個 Three.js 生態系打包進 SSR bundle
- 導致 `entry-server.js` 高達 1,776KB，函式總大小 646MB

**修復策略**:

1. **vite.config.ts**: 將 Three.js 相關套件從 `noExternal` 移到 `external`

   ```typescript
   ssr: {
     noExternal: ["react-icons", "gsap", "react-helmet-async"],
     external: ["three", "@react-three/fiber", "@react-three/drei"],
   }
   ```

2. **PrismScene.tsx / AbyssScene.tsx**: 頂層 `import * as THREE from "three"` 改為動態 import

   ```typescript
   // 舊: import * as THREE from "three";
   // 新: useEffect 內 import("three").then((THREE) => { ... })
   ```

   - Three.js 所有程式碼本來就在 `useEffect` 中（SSR 不會執行）
   - 動態 import 確保 SSR 構建不會嘗試解析 `three` 模組

3. **vercel.json**: `includeFiles` 從 `frontend/dist/server/**` 縮減為只包含 `entry-server.js`
   ```json
   "includeFiles": "{frontend/dist/server/entry-server.js,frontend/dist/client/index.html}"
   ```
